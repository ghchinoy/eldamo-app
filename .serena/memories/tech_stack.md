# Technology Stack

- **Go**: 1.25.5
- **Desktop Framework**: Wails v2 (v2.13.0)
- **Database**: SQLite with `sqlite_fts5` build tag and `sqlite-vec` CGO vector index (768-dim Gemini Embedding 2 vectors).
- **Frontend**: Lit v3, Shoelace Web Components (`@shoelace-style/shoelace` v2.20.1), Vite v8.
- **Transliteration**: Glaemscribe JS engine with Glaemunicode (`tengwar_guni_*`) charsets and WOFF/TTF web fonts.
